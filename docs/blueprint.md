# **App Name**: Lumina VFX Hub

## Core Features:

- Enterprise RBAC System: Secure authentication with JWT and granular role-based access control for Producer, Supervisor, Lead, and Artist tiers.
- Production Hierarchy Manager: Comprehensive tracking of Projects, Sequences, and Shots with linked Task pipelines from Ingest to QC.
- Intelligent Scheduling Assistant: A generative AI tool that analyzes project bid hours and artist availability to recommend optimal task assignments and highlight bottleneck risks.
- Version & Review Pipeline: Streamlined submission system for asset versions including status workflows, frame-specific comments, and feedback loops.
- Visual Production Dashboards: Real-time performance analytics using Recharts to visualize Bid vs. Actual hours and department-specific utilization.
- Consolidated Time Tracking: Integrated time logs and leave management for artists to ensure accurate billing and resource planning in the SQL Server backend.
- SQL Server Repository Architecture: Enterprise-grade database interaction using Sequelize ORM for high-performance CRUD operations on Microsoft SQL Server.

## Style Guidelines:

- Primary Color: Cinematic Crimson (#E6192E) for impact and focus. Background Color: Deep Charcoal (#141212) to evoke a premium dark-room aesthetic. Accent Color: Tech-Violet (#A632E6) to provide clear highlights for interactive components.
- Font pairing: 'Poppins' for headlines and dashboard titles for a geometric, modern look; 'Inter' for body text and high-density data tables to ensure maximum readability.
- Use thin-stroke Lucide icons in white or subtle grey to maintain a sleek, technical enterprise interface.
- A sidebar-centric layout with a fluid grid, following a Netflix-style high-contrast visual hierarchy with spacious horizontal row carousels for project tracking.
- Subtle slide-and-fade transitions between modules and interactive card-hovers to maintain a professional, high-performance feel.
